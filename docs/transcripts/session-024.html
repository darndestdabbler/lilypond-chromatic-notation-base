Session Plan

Session 24: Clefs and key signatures engrave where the Configurator draws them

Why. The Configurator's session 34 (2026-11-07) closes every gap between its preview and the engraving that it can close on its own side. Three remain that only the engine can close. Its LY export spec 1.3.8 records them as known divergences (§5.4d, §5.5):

  • A text clef ignores its height. 'custom clefs are placed by anchor-semitones, but 'text clefs sit at a fixed height of the engine's own. The Configurator draws a text clef with its top edge at the definition's anchorSemi, as it does a glyph.
  • The clef gutter is padded on one side. cnb:clef-gutter-semitones adds blank space after the clef only. The Configurator pads both sides of the clef by the same amount (clef.gutter.paddingH).
  • The key-signature octave under a pitch axis. With the hook set, the engine takes one octave for every key: cnb:keysig-tonic-octave, or else middleCPosition. The Configurator's automatic rule picks, for each tonic, the octave whose span from the tonic to the octave above is centred on the staff's middle, with ties going up (CNBKeySignature.tonicSemi). For the Twinline fixture (middle G) the tonics G♯, A, A♯ and B land an octave apart.

Every new setting defaults to today's behaviour, so every existing golden and harvest stays byte-identical.

  1. Register.
  2. Text clef anchor. Add a setting, say cnb:clef-anchor-semitones (#f = today's fixed placement). It puts a 'text clef's top edge at that semitone through the same path a 'custom clef's anchor-semitones takes (the hook under an axis, middleCPosition otherwise), fractional values included. Add an integration spec on both LilyPond versions, linear and with the hook, that asserts the label's top edge.
  3. Padding before the clef. Add a setting, say cnb:clef-gutter-left-semitones (#f = none), that adds blank space before the clef, in the same units as cnb:clef-gutter-semitones. Add a spec asserting the gap on each side.
  4. Key-signature octave per tonic. Add an automatic mode for cnb:keysig-tonic-octave, say 'centred, that picks each key's octave as the Configurator's rule does, around the semitone the staff centres on: the semitone the hook sends to staff position 0, or the middle line on a linear staff. Add a spec on the Twinline geometry checking all twelve tonics against the Configurator's choice.
  5. README rows for the three settings, and a CHANGELOG line. Write docs/session-sets/024-configurator-gaps/configurator-handoff.md, in the form of the earlier handoffs. It gives each setting's name, default, units and measured behaviour, so the Configurator can export them (its plan's "Export what engine session 24 adds").
