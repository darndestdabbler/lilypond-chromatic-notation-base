Session 18: One include makes any LilyPond score chromatic

Why. On 2026-11-04 musicxml2ly output (Frescobaldi's *Import MusicXML* defaults, --nd --nrp --npl --no-beaming) engraved in Kite on 2.24.2 and 2.26.0 with one \include added after \version: 20 of 20 real scores that musicxml2ly turned into valid LilyPond, and 9 of 9 LilyPond regression files (plan §1.2–1.3). But a plain score renders the heads at default staff size, small, and clips the instrument names at the left margin, because \magnifyStaff #cnb:default-magnify and indent = #cnb:indent are set by hand in every example score and not by the engine.

  1. Register.
  2. Add cnb/score-defaults.ly, included by ChromaticNotationBase.ly unless cnb:score-defaults is #f before the include: a \layout that applies \magnifyStaff #cnb:default-magnify to every Staff, and a \paper with indent = #cnb:indent and whatever else every example score sets that a converted score lacks (compare joy-to-the-world.ly). A score's own \paper and \layout still win. Run both integration suites: a spec that drifts set a different value by hand, so that spec opts out with the flag rather than the baseline moving. Add a spec tests/from-musicxml.ly whose music is the committed musicxml2ly output of the Kainhofer file 21d-Chords-SchubertStabatMater.xml with only the include line added; assert the magnified staff height and that the system's left edge leaves room for the instrument name.
  3. README, new section "Starting from MusicXML" before the walkthrough: Frescobaldi *File → Import/Export → Import MusicXML* with its default boxes (page layout, beaming, rest positions and articulation directions all unchecked), the one include line, the engine's defaults and the opt-out flag; the three musicxml2ly failures seen on real scores (cresc. = #(make-dynamic-script …), note names like fisisisisisis, the nested-tuplet crash) with the fix for each; and MusicFormats xml2ly as the fallback converter.

Work Plan

The plan said indent = #cnb:indent, but cnb/layout.ly already sets that, and its 0 is what clips the names, so the operator chose fixed room in score-defaults (decided 2026-11-04 while planning). cnb:indent and layout.ly stay unchanged.
